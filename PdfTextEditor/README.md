# PDF 편집기 (.NET 10 / WPF)

Acrobat 스타일 PDF 텍스트·페이지 편집기. 콘텐츠 스트림의 실제 텍스트를 교체합니다.

## 실행
    dotnet run -c Release

## 기능 요약
- **파일**: 새로 만들기, 열기, 저장/다른 이름 저장, 인쇄, Word 내보내기, 추출/분할, 종료 시 저장 확인
- **편집**: 텍스트 수정·삭제(묶음), 찾기(Ctrl+F / F3), 되돌리기
- **글꼴**: 언어별 Google Fonts 다운로드, 사용자 TTF 추가
- **그리기·주석**: 도형, 펜, 형광펜, 밑줄, 메모, 링크
- **페이지·문서**: 회전/삭제/이동/삽입/병합/자르기, 워터마크, 머리글/바닥글, 배경색
- **보안**: PKCS#12(.pfx) 인증서 전자서명
- **UI**: Acrobat 스타일 다크 테마, 첫 실행 튜토리얼, 앱 아이콘

## 단축키
Ctrl+N 새로 만들기 · Ctrl+O 열기 · Ctrl+S 저장 · Ctrl+Shift+S 다른 이름 · Ctrl+P 인쇄 · Ctrl+F 찾기 · F3 다음 찾기 · Ctrl+Z 되돌리기

## 제한
OCR, 양식 필드, 비밀번호 보호, 교정(redaction), 완벽한 레이아웃 유지 Word 변환은 미지원.
Word 내보내기는 **추출 가능한 텍스트**만 포함합니다.

## 라이선스
iText 9는 AGPL입니다. 배포·판매 시 상용 라이선스를 검토하세요.
